 Personal Lift Tracker 

A lightweight, web-based workout tracking application designed to log and manage a 5-day Push/Pull/Legs and Upper/Arms split. 

 Live Demo
[ https://lahirupramod.github.io/IronVault/]

Tech Stack
* **Frontend:** HTML5, CSS3
* **Logic:** Vanilla JavaScript (ES6)
* **Storage:** Browser Local Storage API
* **Architecture:** Object-Oriented Programming (OOP)

Features
* **OOP Architecture:** Built using structured JavaScript classes (`Workout`, `UI`, `Store`) mirroring Java-style encapsulation.
* **Persistent Storage:** Workout logs are saved instantly to the browser's Local Storage without requiring a backend database.
* **Dynamic UI:** Add and delete exercises directly from the DOM with real-time updates.
* **Split Tracking:** Custom dropdowns categorized for Push, Pull, Legs, Upper, and Arms routines.
